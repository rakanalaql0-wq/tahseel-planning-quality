# أدوات مساعدة (خارج المنصة)

هذه الأدوات **ليست جزءًا من تشغيل المنصة** ولا تُستدعى منها. المنصة نفسها تبقى
بلا أي اعتماد خارجي (Node وحده). وهذه الأدوات تُشغَّل يدويًا عند الحاجة فقط،
وتحتاج Python ومكتبة `openpyxl`.

## توليد ملف «بنية المقياس» (Excel)

يُنتج `exports/بنية-المقياس.xlsx` — أربع أوراق تطابق ما تعرضه شاشة
«بنية المقياس» في المنصة:

| الورقة | محتواها |
|---|---|
| البنية الكاملة | الأقسام والمحاور والمؤشرات في جدول واحد: لكل صف عدد مؤشراته وتوزيعها على الأدوات، وبنوده وأسئلته، ووزنه ونسبته. صفوف الأقسام والمحاور مجاميع محسوبة من مؤشراتها |
| شجرة المقياس | المستويات الثلاثة بمقارنة الوزن المعلن بالمحسوب، ومالك كل مؤشر وخطة عينته ووصفه |
| بنود التحقق | نص كل بند بوزنه النسبي وحالته، منسوبًا إلى مؤشره وقسمه ومعياره |
| أسئلة الاستبانات | نص كل سؤال وموضع قياسه، منسوبًا إلى مؤشره |

جمع المستويات يستعمل `SUMIFS` على عمود «المستوى» لا جمع المدى: المدى يضم
صفوف المحاور وهي نفسها مجاميع، فجمعه يحتسب كل قيمة مرتين.

```bash
node tools/dump-metric.mjs /tmp/metric.json
python3 tools/build-metric-workbook.py /tmp/metric.json "exports/بنية-المقياس.xlsx"
```

## توليد ملف «خطة القياس» (Excel)

يُنتج `exports/خطة-القياس.xlsx` من بنية المقياس المعتمدة في قاعدة البيانات:
ورقة رئيسية بالمنفّذين وأعدادهم، وورقة مؤشرات بقائمة منسدلة لاختيار المنفّذ.

```bash
pip install openpyxl

# 1) استخراج بنية المقياس من قاعدة البيانات إلى JSON
node tools/dump-scale.mjs /tmp/scale.json

# 2) بناء ملف Excel منها
python3 tools/build-measurement-plan.py /tmp/scale.json "exports/خطة-القياس.xlsx"
```

الملف يُعاد توليده متى عُدّلت بنية المقياس من شاشة الإدارة، فيبقى مطابقًا
للمعتمد في النظام.

### قاعدة «مرات القياس»

المعادلة في الملف تحاكي `requiredCount()` في `src/lib/scoring.js` حرفيًا:

| الدورية | مرات القياس |
|---|---|
| قبل البداية / المنتصف / النهاية / سجل مستمر | 1 |
| المنتصف والنهاية | 2 |
| عدد ثابت | الحد الأدنى المحدد |
| عينة من اللقاءات | `MAX(1, ⌈اللقاءات × النسبة ÷ 100⌉, الحد الأدنى)` |
| بعد كل نشاط رئيس | عدد الأنشطة الرئيسة |

تحقُّق: لبرنامج من 12 لقاءً ونشاطين، يعطي الملف والمحرك 50 مرة قياس للمقياس كاملًا.
